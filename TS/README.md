# タイムスケジュール自動作成ツール（Python版）

JSONフォーマットのイベントデータからExcelタイムスケジュールを自動生成します。

## 機能

- **タイムラインシート** → 日付別にイベント・フェーズを時間軸で表示
- **スタッフマスターシート** → テクニカル・担当者リスト
- **イベント詳細シート** → フェーズ別の詳細情報（時刻・担当者）
- **色分け対応** → 仕込み=黄、本番=緑、撤収=赤で自動着色

## 使い方

### 1. サンプルで実行（データ確認用）

```bash
python3 timeschedule_generator.py
```

→ `timeschedule_sample.xlsx` が生成されます

### 2. JSONファイルから生成

```bash
python3 timeschedule_generator.py data.json output.xlsx
```

## JSONデータフォーマット

```json
{
  "staff_data": {
    "technical": ["名前1", "名前2"],
    "personnel": ["担当者1", "担当者2"]
  },
  "events": [
    {
      "date": "2026-09-12",
      "name": "イベント名",
      "type": "stage",
      "location": "場所",
      "phases": [
        {
          "type": "setup",
          "label": "ラベル（任意）",
          "startTime": "09:00",
          "endTime": "14:00",
          "technical": ["名前1"],
          "personnel": ["担当者1"]
        }
      ]
    }
  ]
}
```

### イベントタイプ

| type | setup | performance | teardown |
|------|-------|-------------|----------|
| stage | 仕込み | 本番 | 撤収 |
| exhibition | 搬入 | 開催 | 搬出 |
| workshop | 準備 | 開催 | 片付け |
| talk | 準備 | トーク | 片付け |

## 出力内容

### シート1: タイムスケジュール
- 行：イベント（日付/名前/場所）
- 列：時間軸（9:00-23:00）
- セル：フェーズ情報（色分け＋スタッフ名表示）

### シート2: スタッフマスター
- テクニカル担当者リスト
- 担当者リスト

### シート3: イベント詳細
- 全フェーズの詳細情報
- 日時・スタッフ・ラベル等

## 例

ブラウザ版で作成したデータをJSONでエクスポートして、このスクリプトに渡すだけで、整形されたExcelが生成されます。
