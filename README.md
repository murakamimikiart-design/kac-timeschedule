# KAC タイムスケジュール作成ツール

京都芸術センター（KAC）の公演・展示用タイムスケジュール（仕込み〜本番〜バラシ）を
ブラウザだけで作成・共有できるツールです。サーバー不要・インストール不要。

## 種類の選択（運営 / 設営）

**編集モードの右サイドバー（入力フォーム）**の先頭で「運営」か「設営」を選びます。選んだ種類に応じて、生成される表の形が変わります。それぞれ **別のデータとして保存** され、切り替えても消えません（フォームの入力内容は切り替え先に引き継がれます）。ツールバー左端のバッジは現在の種類を示し、クリックすると入力フォームが開きます（「📝 フォーム」ボタンで表示/非表示）。

| ベース | 用途 | 行の構成 | サンプル |
|---|---|---|---|
| 🏛 **運営** | 京都芸術センター運営側の複数事業の進行表 | **事業（場所）ごとに1行**。隣の「担当」列にスタッフ名を羅列、セルはフェーズ名（仕込み＝黄／本番＝緑／撤収＝赤） | 9月イベント（明倫レコード倶楽部・UAC・TARO）＋テクニカルのMT・休憩 |
| 🎭 **設営** | 舞台・美術の仕込み〜本番〜バラシ | **テクニカル＋担当者ごとに1行**（舞台／照明／音響／出演者／制作／KAC…）。フェーズで担当にチェックした行にブロック。隣り合う行は結合、担当未選択＝全行 | 空のひな形（フォームのサンプルは役職名だけの汎用データ） |

どちらも入力フォームから表を生成する前提の作りです（`TS/timeschedule_generator.py` のブラウザ版に相当）。Excel出力は「タイムスケジュール」「スタッフマスター」「イベント詳細」の3シートになります。

「新規」「サンプル」は選択中のベースに合わせて動きます。共有URLやJSONにもベース情報が含まれ、開いた側で自動的に同じベースに切り替わります。

## 画面構成

| 場所 | できること |
|---|---|
| **右サイドバー：入力フォーム**（編集モード） | 種類（運営／設営）・スタッフ登録を記入し、運営なら「イベント（イベント名・日付・場所・種別）」、設営なら「プログラム名・事業タイトル・種別・会場・事業日程」＋「日程（名称・日付・場所）」を記入。運営ではフェーズごとに「場所」も指定でき、イベントの場所と違えば「イベント名（場所）」の行が別に増える。設営で同じ日に場所の違う日程があると、その日の行が場所ごとに分かれ、名前の隣に「場所」列が出る。日程の名称（仕込み／本番① など）は表の日ラベルになる。各日程／イベントの下にフェーズ（種別＝仕込み・本番・撤収・**休憩**／ラベル／時間／担当）を並べる。**入力すると自動で表に反映**（オフにして「表に反映」ボタンでまとめて反映も可）。担当はドロップダウンから追加し、チップの×で外す |
| **編集**（表） | マス目をドラッグしてブロック作成 ／ クリックで**画面下のバー**から内容・色・行を編集 ／ ドラッグで移動・右端で長さ変更 ／ 行・日の追加削除。フォーム由来のブロック（左上に青い印）は反映のたびに作り直され、手で足したブロックは残る |
| **閲覧** | 印刷用のきれいな表示。「印刷 / PDF」ボタンでA4に出力 |
| **本番進行** | 現在時刻の赤線、進行中のブロックをハイライト、次の予定までのカウントダウン |

### テクニカル（MT・休憩）※運営
運営フォームの「テクニカル（MT・休憩）」に、日付・種別（MT／休憩／その他）・時間・対象（未選択＝テクニカル全員）を登録すると、その日に対象のテクニカルが担当に入っているイベントの行に、MT（水色）・休憩（灰色）のブロックが重なって表示されます（短いブロックは前面に描かれ、下のブロックのラベルは隠れない区間に分かれて表示）。表の上で動かすとフォームに書き戻されます。

### 休憩
フェーズの種別に「休憩」があります（灰色）。設営で一部の人だけ休憩時間が違う場合は、休憩フェーズを複数作って担当を分ければ、その人の行だけ別の時間に表示されます。

### 表とフォームの双方向同期
フォーム由来のブロック（左上に青い印）を表の上で動かす・伸縮する・下のバーで文言や色を変えると、フォームの元のフェーズ（時間・担当・ラベル・色）に書き戻されます。表の灰色部分（時間外）の境目にある「入」「退」ハンドルをドラッグすると、その日の入り〜退館が変わり、フォームの「時間」にも反映されます。フォーム由来のブロックを削除すると、確認のうえ元のフェーズも削除されます。逆に、表の上で手で作ったブロックは下のバーの「→ フォームに追加」でフォームのフェーズに変換できます（色から種別を判定、覆っている行から担当を判定。未登録の行名はスタッフに追加）。

### 日程の時間（入り〜退館）
表の「入」「退」ハンドル（編集モードで灰色部分の境目に表示）をドラッグすると、その日の時間外が灰色になり、退館時刻に赤線が引かれます（未設定なら「設定」の共通値）。

## 保存と共有

- 変更は自動でブラウザ（localStorage）に保存されます
- **JSON保存 / JSON読込** … ファイルとして保存・別のPCで開く（旧Python版の `sample_data.json` 形式は入力フォームに取り込まれます）
- **Excel** … セル結合・色付きの .xlsx を書き出し
- **共有URL** … スケジュールデータをURLに埋め込んで共有（相手はURLを開くだけ）
  - 「閲覧モードで開くURL」は最初から閲覧表示で開きます

## ローカルで動かす

`index.html` をダブルクリックで開くだけでも動きますが、共有URL機能を確実に使うには簡易サーバーで開いてください：

```bash
python3 -m http.server 8765
```

→ http://localhost:8765/

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（例：`kac-timeschedule`、Public）
2. このフォルダをプッシュ

   ```bash
   git init
   git add .
   git commit -m "KAC timeschedule tool"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/kac-timeschedule.git
   git push -u origin main
   ```

3. リポジトリの **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → Save
4. 数分後に `https://<ユーザー名>.github.io/kac-timeschedule/` で公開されます

以降は `git push` するだけで更新されます。

## データ形式（JSON）

```json
{
  "base": "ops",
  "meta": { "program": "", "title": "公演名", "dates": "2026年10月1日(木)ー2日(金)", "venue": "京都芸術センター講堂", "updated": "2026-09-14" },
  "settings": { "startHour": 9, "endHour": 23, "slot": 30, "openTime": "09:30", "closeTime": "22:00" },
  "days": [
    {
      "id": "d1", "date": "2026-08-28", "label": "仕込み", "notes": "",
      "lanes": [ { "id": "a1", "name": "UAC\n(講堂)", "staff": "鬣さん\n村上美樹" }, { "id": "a2", "name": "TARO\n(北ギャラリー)", "staff": "鬣さん" } ],
      "blocks": [
        { "id": "b1", "start": "14:00", "end": "17:00", "lane0": 0, "lane1": 1,
          "text": "リハーサル\n14:00-17:00", "bg": "#FFF100", "fg": "#000000",
          "bold": true, "size": "m", "vertical": false }
      ]
    }
  ],
  "notes": "確認事項など",
  "form": { "technical": ["十河・管理"], "personnel": ["青田"], "events": [ { "date": "2026-09-12", "name": "UAC", "type": "exhibition", "location": "講堂", "phases": [ { "type": "setup", "label": "設営", "startTime": "12:00", "endTime": "20:00", "technical": ["十河・管理"], "personnel": ["青田"] } ] } ] }
}
```

- `form` … 入力フォームの内容（旧Python版の `staff_data` / `events` と同じ構造。加えて `type`＝設営の公演種別、各イベントの `start` / `end`＝その日の入り〜退館、フェーズ種別 `break`＝休憩）。フォーム由来のブロックには `gen`（フェーズID）が付き、反映のたびに作り直されます

- `base` … `ops`（運営）または `setup`（設営）
- 行（lanes）は **日ごと** に持ちます（`days[].lanes`）。その日にある事業・スタッフの行だけが並びます。トップレベルの `lanes` は新しい日を作るときのひな形
- `lanes[].loc` … 「場所」列（設営で場所ごとに行を分けたとき）。どれかの行に入っていれば列が表示される
- `lanes[].staff` … 「担当」列に表示するスタッフ名（改行区切り）。運営ベースでは常に表示、設営ベースでは入力がある場合のみ表示
- `lane0` / `lane1` … ブロックが占める行の範囲（0始まりのインデックス、両端を含む）
- `openTime` / `closeTime` … 利用時間外を灰色表示、終了時刻に赤線
